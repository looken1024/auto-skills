# 菜谱图文版式参数

## 步骤图

| 参数 | 值 | 说明 |
|---|---|---|
| WIDTH | 1080 | 所有图统一宽度，位置比例才对得上 |
| MARGIN_X | 0.070 | 左右各 7%，文字块不贴边 |
| TOP | 0.045 | 距顶 4.5%（用户明确要求文字在上方） |
| FONT_RATIO | 0.042 | 1080 宽时字号 45px |
| LINE_SPACING | 1.45 | 中文正文行距 |
| BOX_ALPHA | 150 | 黑底约 59% 不透明，压住底图又不死黑 |
| RADIUS_RATIO | 0.012 | 圆角 |

文字块最多占图片高度 32%，超出时字号自动往下缩（18px 保底）。

## 封面

- 画布 1080×1440（3:4，与步骤图一致）
- 底图 `cover_fill`：等比放大到填满，居中裁剪，不变形
- 顶部渐变：46% 高度，alpha 215 → 0，幂次 1.6（上浓下透）
- 左侧边距 78px
- kicker：27px，字距 4，奶油白 alpha 205
- 主标题：172px，字距 14，纯白，偏移 (2,4) 的 43% 黑投影
- 红色短线：96×7，`#C63E28`
- 英文副题：24px，字距 11，alpha 170

## 字体

- 中文：Noto Serif SC Bold（思源宋体），woff2 Pillow 可直接加载
- 英文：Noto Serif SC Latin 700
- 回退：`wqy-zenhei.ttc`（黑体，无衬线，观感偏普通）
- 字体放 `assets/fonts/`，由 `scripts/setup_fonts.sh` 从 jsdelivr 下载

## 为什么这样排

- 宋体比黑体更像餐厅菜单/杂志，标题才有“设计感”。
- 字距拉开是廉价但有效的提升手段：172px 的四个字加 14px 字距，视觉上更稳。
- 顶部渐变而不是整块透明黑底：菜还能透出来，不像 PPT 遮罩。
- 红色只用在 96px 的短线上，面积小，做点缀不做主色。
