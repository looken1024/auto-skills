# 微头条写作规则（数据迭代快照）

> 每次反馈分析后更新。格式：规则 + 支撑数据 + 状态。
> 初始化于 2026-09-14 首次数据分析。

## 生效中

1. **首句必须是「具体事件+数字/人物」，禁止泛议题开头**（数据迭代 2026-09-14）
   - 数据：故事型首句（"面试全过offer到手谈好40万""4块牛肉干64块5""693分去北大医学部"）展现 813-1659；议题型首句（"总有人在等涨工资""大家对油价敏感度越来越高"）展现 26-86。差 10-20 倍。
   - 做法：写稿 prompt 硬规则——首句禁止以"很多人觉得/大家/说实话/最近"开头；首句必须含具体数字、金额、人物或已发生动作。

2. **选题优先挑有具体当事人/金额/事件的题，泛民生议题降权**（数据迭代 2026-09-14）
   - 数据：同等发布条件下，具体事件类（offer被砍/牛肉干复秤/北大改志愿）平均展现 1200+，议题类（油价/涨工资/调休/控糖）平均 <100。

3. **场景化写法能救政策类选题**（数据迭代 2026-09-14）
   - 数据："跨院检查互认"（纯政策题）拿到 695/35，靠的是开头写具体看病场景（A医院做完CT到B医院重拍）而非政策条文本身。政策题必须落到具体人的具体遭遇。

## 观察中（样本不足）

- 凌晨发布（0-3 点）冷启动展现 209-225，与白天中位数接近，暂不调整发布时段。
- 点赞集中在情绪共鸣强的职场/教育题材，样本少待验证。
