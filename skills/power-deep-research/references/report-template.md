## Retrieval Quality Appendix

Append or summarize this section for Pro/Ultra reports, high-stakes topics, conflicting evidence, weak retrieval, or when the user asks for methodology. For routine Standard answers, keep it internal and only mention confidence/gaps briefly.

```markdown
## Retrieval Quality

### Coverage Assessment

| Dimension | Status | Sources | Best type | Confidence |
|---|---|---|---|---|
| Official/primary facts | covered | N | primary / secondary | high / med / low |
| Data and metrics | covered / partial / missing | N | | |
| Independent analysis | | | | |
| Examples/cases | | | | |
| Risks, limits, criticism | | | | |
| Implications for user goal | | | | |

**Overall confidence**: High / Medium / Low

> **High**: Multiple independent primary sources, recent data, key dimensions covered, no critical gaps.
> **Medium**: Some dimensions rely on secondary sources, partial data, minor gaps acknowledged.
> **Low**: Sparse or low-quality sources, significant gaps, or fast-moving topic with stale data.

### Evidence Strength Summary

| Key claim | Strength | Basis |
|---|---|---|
| <claim> | strong / adequate / weak | e.g., "2 primary sources agree" or "single community post" |
| ... | | |

**Legend**:
- Strong: Primary source OR 2+ independent reliable sources
- Adequate: One reliable secondary source OR primary source with minor caveat
- Weak: Single low-quality source, community post, or extrapolation

### Gaps And Limitations

- **Uncovered dimensions**: <list any missing or partial dimension above, with reason>
- **Stale sources**: <list any source exceeding freshness threshold for its topic type>
- **Unresolved conflicts**: <list any critical or material contradictions not resolved>
- **Data quality issues**: <marketing bias, missing methodology, paywalled data>

### Research Reproducibility

**Date of research**: YYYY-MM-DD

**Searches performed**:
1. `<exact query>` — N results, used M
2. ...

**Pages fetched and read**:
- [Title](URL) — date, author, why selected

**Pages considered but not used**:
- [Title](URL) — reason (stale, marketing-only, paywalled, duplicate, low quality)

> Optional: install markitdown (`pip install markitdown`) for cleaner page extraction on document-heavy research tasks.
```

## Writing Rules

- Lead with the answer, then prove it.
- Group by findings, not by source.
- Put citations next to the claims they support.
- Use tables for comparisons and numbers.
- Label uncertainty plainly.
- Do not fabricate missing data; write "not found in available sources" when necessary.
