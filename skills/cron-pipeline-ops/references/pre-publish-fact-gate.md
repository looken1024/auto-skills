# 发布前事实/口径门禁（内容流水线通用）

复审脚本只抓「AI 味」，**抓不出事实错误**。以下门禁来自 2026-09-13 一次外部模型复盘：当天 5 条已发内容里 5 处事实/口径问题全被点出。凡内容流水线（微头条 / 公众号 / 图文）发布前都应跑一遍。

## 六条门禁

1. **引用数据先核对原文口径**
   - 实例：把「**211** 本科比 **非211** 本科起薪高 11.8%」写成「985 比双非高 11.8%」；把「歧视性因素导致的起薪**差异占比** 62.51%」写成「62.51% 的差距纯粹是看出身」。
   - 做法：引调研/专家/企业声明的数字前，在原文确认 **主体、口径、年份** 三件事。
2. **检查统计数字的论证方向**
   - 实例：用「流失率 0.50%」论证「真想留下的人不多」——0.5% 在零售业是极低，恰恰说明留下的人多，**论据反了**。
   - 做法：凡用数字撑观点，先问「这个数算高还是低，支持我的结论吗」。
3. **二手位次/排名一律降级表述**
   - 实例：多篇转载只写「名列前茅」，稿子里写了「浙江省第二」。
   - 做法：拿不到官方口径就不写具体名次，改「全省前列」。
4. **自己算的账必须标注是假设**
   - 实例：「按一天 3000 人、每人多收 5 块，一个月 45 万」是自建估算模型，未标注，易被截图当成实锤。
   - 做法：写成「咱假设…」，或干脆不给乘式。
5. **别做选择性呈现**
   - 实例：引企业声明时省略了紧邻的出口（原话里还有「特别专业者可留企做培训师傅」，只提「不续签」会被评论区反噬）。
   - 做法：引原话时把反例/出口一起带上，观点靠判断力而不是靠截断。
6. **推测与事实分开写**：推测用「我猜/大概是」，肯定语气只留给有信源的句子。

## 批量发布还要看配额（同日多条时）

- **结尾问句最多 3 条，且不得有两条一字不差**（实测事故：同日两条结尾问题完全相同，被判定为“模板批量生产”）。
- **至少 1 条换情绪**（认知好奇型，而不是愤怒/憋屈型）。
- **结构至少错开一次**（默认「热点→细节→情绪→反问」可换成「先给结论再叙事」或「从反常识细节切入」）。
- 选题半径别全挤在一条赛道上。

## 外部复盘怎么做（强烈推荐）

每天收工后，把当天已发内容整批喂给外部模型（不同厂商的网页版或 API）做复盘。开「深度思考」+联网搜索效果最好（能引用信源核你的数据）。

已验证有效的 prompt 结构：

```
我在 XX 平台运营一个账号，人设/风格要求是：<风格铁律一句话>。下面是我今天发的 N 条（含发布时间），请以资深内容运营视角复盘。

<当天内容>
【时间】正文...
</当天内容>

请按这个结构回答：
1）逐条一句话点评：开头钩子强度、观点是否清晰、有没有事实风险；
2）这几条共有的套路和盲点（选题分布、结构同质化、情绪浓度、结尾方式）；
3）指出任何事实性错误、夸大或争议/合规风险（新闻类内容，事实必须站得住）；
4）给 3 条明天就能落地的改进建议 + 一个最该避开的方向；
5）最后单独一行：只保留一条你留哪条、为什么。

直接给分析，不要客套，不要复述我的要求。
```

驱动网页版模型的具体操作（登录/验证码/发送/抓回复）见 `references/web-chat-automation.md`。

## 收到复盘后怎么办

- 复盘发现的**事实错误**：优先修正已发布内容（多数平台支持编辑），并在下一次写作时把该错误类型加进本清单。
- **套路/同质化问题**：写进任务 prompt 的硬性条款（而不是只写在笔记里），否则下一次还会犯。
- 复盘结论要**落到文件**（如 skill 的 `logs/` 目录），否则下次从零开始。
