# 公众号图集标题规则（2026-11-03 两次用户纠正）

## 规则

| 类型 | 标题 |
|---|---|
| `news` 图文消息 | 契合该地点/景点的描述；**主题是具体地名/景点时，地名必须出现在标题里**；**禁止「每日图集」「图集」** |
| `newspic` 贴图 | 仍用 `{topic}·每日图集（date）`（用户只要求改文章任务，别顺手改） |

## 风格禁区（用户明确否掉）

第一版改成诗意拟人，被批“不要这么诗意，有点像 AI 生成的”。被点名的例子：

- 阿尔山天池，云影落入森林的眼
- 平潭蓝眼泪漫过夜滩，似星河碎落海中
- 莫雷诺冰川：冰崩时刻的蓝白史诗

**要的是平实、具体、像人写的**。用户认可的候选类型：

- **直白信息型**：阿尔山天池，火山口上的那潭水 / 莫雷诺冰川，阿根廷最出名的一条冰川
- **轻游记型**：去阿尔山看天池，得先爬一段林间栈道 / 在莫雷诺冰川，能一直听见冰裂的响声
- **短句口语型**：阿尔山天池，水很静，风很凉 / 莫雷诺冰川，蓝得很实在
- **细节观察型**：莫雷诺冰川的冰，是那种透亮的蓝 / 平潭蓝眼泪亮起来的时候，浪是蓝的
- **提问型**：阿尔山天池的水，到底从哪来（只在有事实依据时用）

## 工作流：先给候选让用户挑，别直接定稿

用户对标题口味敏感，改规则时**先列一批候选对比**（同一主题按几种风格各写几条），让他说“要哪几种、各占多少比例”，再把口径写进 prompt。别自己拍板一种风格就上线。

本次给出的风格分类（A–F，用户可按比例混用）：

- **A 直白信息型**：阿尔山天池，火山口上的那潭水 / 莫雷诺冰川，阿根廷最出名的一条冰川
- **B 轻游记型**：去阿尔山看天池，得先爬一段林间栈道 / 在莫雷诺冰川，能一直听见冰裂的响声
- **C 短句口语型**：阿尔山天池，水很静，风很凉 / 莫雷诺冰川，蓝得很实在
- **D 细节观察型**：莫雷诺冰川的冰，是那种透亮的蓝 / 平潭蓝眼泪亮起来的时候，浪是蓝的
- **E 提问型**：阿尔山天池的水，到底从哪来（只在有事实依据时用，否则易编造）
- **F 克制书面型**：阿尔山天池：火山口积水形成的湖 / 平潭蓝眼泪：夜光藻带来的海岸荧光

跨 4–5 个不同主题各列 5–6 条，比单主题更容易看出风格差异。

## 实现

`pexels_gallery_draft.py` 的 `make_title(topic)`：

- 调 opencode-go `deepseek-v4.1-flash`，prompt 明确：12-24 字、地名后加「，」或「｜」、泛场景不要硬编地名、禁浮夸营销词、禁「每日图集」、只输出标题
- 校验：6-32 字且不含「图集」，否则回退 `{topic}｜一眼心动的风景`
- API 细节：无代理 opener + **浏览器 User-Agent**（否则 403/1010）+ `stream=false` + `reasoning_effort=low` + 足够 `max_tokens`

## 验证

真跑一次 news 稿，用 `draft/batchget`（`r.content.decode('utf-8')`）确认标题落库；只测 `make_title()` 不够，标题只在非 dry-run 路径生成。
