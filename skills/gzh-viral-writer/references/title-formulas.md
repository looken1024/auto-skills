# 标题公式速查卡

> 写标题时按此速查，选 2-3 个公式各出一版，挑最有情绪张力的。

## 八大公式

### 1. 反常识冲突（首选，点击率最高）
```
模板：X不是A，是B / 越X越B
例：裁员90%，不是保命是自杀
例：AI时代最该学的不是AI，是怎么保持自己的活人感
例：好的婚姻，都是"演"出来的
```

### 2. 群像设问
```
模板：那些（做了某事的）某类人，真的（结果）了吗？
例：那些悄悄搞副业的年轻人，真的赚钱了吗？
例：副业变"负"业的职场人，到底做错了什么？
```

### 3. 数字悬念
```
模板：具体数字 + 意外/反差结果
例：副业月入2万被鄙视：发展副业，你需要知道这3件事
例：一段婚姻走到尽头的三个先兆
例：发了28篇笔记，只涨了120个粉丝，问题出在哪？
```

### 4. 小切口判断
```
模板：X好不好，看"Y"就知道
例：婚姻好不好，看"饭桌"就知道！
例：中年最通透的活法：沉浸式做自己
```

### 5. 紧急通报（蹭热点）
```
模板：短句重复 + 冒号 + 感叹号
例：裁员！裁员！裁员！
例：突然宣布：大裁员！
```

### 6. 身份代入
```
模板：人到X / X岁以后 + 感悟
例：中年以后，要和自己来三次和解
例：中年以后最好的养生：断舍离
```

### 7. 场景共鸣
```
模板：具体时间地点 + 一句对话
例：凌晨1点下班打车时，司机问我："姑娘，你这样拼值得吗？"
```

### 8. 权威背书
```
模板：机构/名人 + 反常识观点
例：马斯克：顶级高手都在用"第一性原理"
例：哈佛研究：裁员幸存者的业绩下滑20%
```

## 组合技（爆款标题常见复合结构）

```
钩子 + 冒号 + 利益点：
  他写公众号3个月变现20万：普通人没告诉你的3个真相
人群标签 + 具体场景 + 情绪词：
  领导总说我汇报没重点？情商高的人都懂的5个沟通技巧
悬念 + 反差 + 情绪爆点（三段式）：
  95后开着宝马收麦子：是作秀还是新农人？
```

## 硬性规则

1. **25 字以内**——手机端标题栏截断线
2. **核心词前置**——把"保洁阿姨"放句首，别藏在"关于酒店卫生"后面
3. **拒绝空泛惊叹**——"震惊！！！"不如一个具体数字
4. **每篇出 3 个候选**——分别用不同公式，选情绪最抓人的
5. **自查**：把标题念出来，问自己"我会点开吗？"——不会就重写
