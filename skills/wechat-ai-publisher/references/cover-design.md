# 图集封面版式与调色

目标：一张封面里竖着并排几条当期图集的图，**纯图、不叠任何文字**。标题只走草稿的 `title` 字段。

## 为什么“六条等宽”经常不好看

- 六张照片的地平线各不相同，横穿画面的水岸线会变成台阶——人对水平线极度敏感，一眼就看出是硬剪的。
- 太阳在不同图里出现两三次，大小、位置、清晰度都不一致，产生“时空错乱”。
- 色温和亮度一高一低，竖条像百叶窗；给整张盖一层橙色滤镜只会让所有条一起变脏。
- 前景（树枝/枯树/草岸）各自抢戏，六个条都满，没有视觉焦点。

## 版式选择

| layout | 结构 | 适用 | 主要问题 |
|---|---|---|---|
| `grid` | 左 62% 主图 + 右 2×2 四格 | 默认推荐，有明确视觉焦点 | 需要至少 5 张可用图 |
| `main3` | 左 62% 主图 + 右 3 条 | 图少、想要更“栏目感” | 右侧三条 140px 太窄，画面局促 |
| `three` | 三条等宽 | 素材只有 3–4 张 | 每格太宽，容易被问“为什么不放满” |
| `six` | 六条等宽 | 素材同色系同时段（如整组日落） | 地平线/多太阳问题最重 |

实现：`scripts/cover_layout.py --layout grid|main3|three`；六条用 `scripts/cover_card6.py --no-text`。

## 选图（决定成败的一步）

在拼接前先算每张图的 HLS：

- 色相：只留暖色（<70° 或 >320°）。
- 饱和度：>0.20，低于这个值的多是雾天/阴天，拼进去必脏。
- 亮度：0.22–0.52，太亮的白天图会把整张拉花。

不够数时**逐级放宽**（先放宽饱和度，再放宽色相），而不是直接塞冷色图。

## 色彩统一

Reinhard 简化版（对每条图的 RGB 通道做均值/方差匹配到参考图）：

```python
for c in range(3):
    sm, ss = src[:, :, c].mean(), src[:, :, c].std()
    rm, rs = ref[:, :, c].mean(), ref[:, :, c].std()
    src[:, :, c] = (src[:, :, c] - sm) * (rs / max(ss, 1e-6)) + rm
```

参考图选饱和度最高的那张，不要选最亮或最暗的。之后再叠 5% 暖色（`Image.blend(canvas, (255,150,80), 0.05)`）、对比 1.03–1.04、上下 10% 极轻暗角（alpha ≤12）。

## 地平线与接缝

- 水天线检测：灰度图按行求梯度均值，平滑后取 15%–85% 区间的最大值；返回相对高度。
- 裁剪时让该线落在画面 `0.46` 高度，各条才对齐。
- 接缝：每条左边缘做 18–24px 线性 alpha 羽化，与已有内容叠加（`paste(tile, (x0 - f//2, 0), mask)`）。
- **先铺底**：canvas 先用主图 `crop_fill` 铺满，再叠条；否则羽化边缘会露出白底细线。

## 自检与交付

1. `vision_analyze` 逐张问：“地平线是否统一 / 有没有多个太阳 / 有没有跳色”。
2. 一次给用户 2–3 个版式样张（六条 / 一大三小 / 一大四格），让他挑。
3. 定稿后固定版式，后续图集直接复用，不再每次试。

## 其他

- 尺寸 1080×648；公众号列表 2.35:1 时再出 1080×460。
- 中文用系统 `wqy-zenhei.ttc`（黑体，接近资讯卡片观感）；纯图版不需要字体。
- 用户删掉草稿里某张图后，封面按剩余张数重排，不要沿用旧封面。
